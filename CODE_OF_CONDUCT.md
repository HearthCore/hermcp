# Code of Conduct

Be respectful and constructive. No harassment, discrimination, or personal attacks.
Assume good intent, give specific feedback, and keep discussion on the technical matter.

Maintainers may remove comments, close issues, or block users who do not follow this.
Report conduct problems via a private GitHub security advisory draft or by contacting the
maintainers through their GitHub profile.

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) 2.1.
